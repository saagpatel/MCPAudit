# Explore the synthetic sandbox

The [sandbox files](../../examples/sandbox) demonstrate MCPAudit against
program-owned synthetic data. The browser page is static. The bundled `demo`
command uses its synthetic configuration without discovering workstation
configs or connecting to a server.

```sh
mcp-audit demo
```

The fixtures illustrate findings and the boundary of config-only inference.
They are examples, not evidence about real MCP servers or client runtimes. For
the fixture inventory and browser walkthrough, see the
[sandbox README](../../examples/sandbox/README.md).
